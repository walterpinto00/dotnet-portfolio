Paso a Paso: Index de Autor con Services + ViewModels

🍽️ Analogía del Restaurante

Imaginen que su código es como un restaurante:

❌ ANTES

El mesero (Controlador) va a la cocina, cocina la comida, y la sirve. Todo el trabajo lo hace una sola persona.

✅ DESPUÉS

El mesero (Controlador) solo toma el pedido y lo lleva al cocinero (Servicio). Cada quien hace su trabajo.

Eso es todo. El Controlador deja de hablar directo con la base de datos. Ahora le pide los datos al Servicio.

📁 Estructura Final del Proyecto

BibliotecaApp/ ├── Controllers/ │ └── AutorController.cs ← MODIFICAR ├── Data/ │ └── ApplicationDbContext.cs ← NO TOCAR ├── Models/ │ ├── Autor.cs ← NO TOCAR │ ├── Libro.cs ← NO TOCAR │ └── Prestamo.cs ← NO TOCAR ├── Services/ ← CREAR CARPETA │ ├── IAutorService.cs ← CREAR │ └── AutorService.cs ← CREAR ├── ViewModels/ ← CREAR CARPETA │ └── AutorIndexViewModel.cs ← CREAR ├── Views/ │ └── Autor/ │ └── Index.cshtml ← MODIFICAR └── Program.cs ← MODIFICAR

1 Crear las carpetas Services y ViewModels

En Visual Studio:

💡 Tip: Las carpetas se crean a nivel de proyecto, no dentro de otras carpetas.

2 Crear el ViewModel del Index

ViewModels/AutorIndexViewModel.cs

Clic derecho sobre la carpeta ViewModels → Agregar → Clase → nombrar AutorIndexViewModel.cs

namespace BibliotecaApp.ViewModels
{
    public class AutorIndexViewModel
    {
        public int Id { get; set; }
        public string Nombre { get; set; } = string.Empty;
        public string Nacionalidad { get; set; } = string.Empty;
        public DateTime? FechaNacimiento { get; set; }
        public int TotalLibros { get; set; }  // ← ¡Dato extra!
    }
}
💡 ¿Por qué? Este ViewModel es lo que la vista va a recibir. Tiene los datos exactos que el Index necesita mostrar, incluyendo TotalLibros (un dato calculado que no existe en la base de datos).

3 Crear la Interfaz del Servicio

Services/IAutorService.cs

Clic derecho sobre la carpeta Services → Agregar → Nueva interfaz → nombrar IAutorService.cs

using BibliotecaApp.ViewModels;

namespace BibliotecaApp.Services
{
    public interface IAutorService
    {
        Task<IEnumerable<AutorIndexViewModel>> ObtenerTodosAsync(string? buscar);
    }
}
💡 ¿Por qué? Es el contrato. Define qué métodos debe tener el servicio. El controlador dependerá de esta interfaz, no de la implementación concreta.

4 Crear el Servicio (la implementación)

Services/AutorService.cs

Clic derecho sobre la carpeta Services → Agregar → Clase → nombrar AutorService.cs

using BibliotecaApp.Data;
using BibliotecaApp.ViewModels;
using Microsoft.EntityFrameworkCore;

namespace BibliotecaApp.Services
{
    public class AutorService : IAutorService
    {
        private readonly ApplicationDbContext _context;

        public AutorService(ApplicationDbContext context)
        {
            _context = context;
        }

        public async Task<IEnumerable<AutorIndexViewModel>> ObtenerTodosAsync(string? buscar)
        {
            var query = _context.Autores.AsQueryable();

            if (!string.IsNullOrWhiteSpace(buscar))
            {
                query = query.Where(a => a.Nombre.Contains(buscar));
            }

            // ✅ Mapeamos de Autor (modelo) a AutorIndexViewModel
            return await query.Select(a => new AutorIndexViewModel
            {
                Id = a.Id,
                Nombre = a.Nombre,
                Nacionalidad = a.Nacionalidad,
                FechaNacimiento = a.FechaNacimiento,
                TotalLibros = a.Libros.Count  // ← Dato calculado
            }).ToListAsync();
        }
    }
}
💡 ¿Por qué? Aquí está la lógica real: consultar la base de datos, filtrar si hay búsqueda, y mapear los resultados al ViewModel. El controlador ya no hace esto.

5 Modificar el Controlador

Controllers/AutorController.cs

Abrir Controllers/AutorController.cs y reemplazar todo su contenido con esto:

using BibliotecaApp.Data;
using BibliotecaApp.Models;
using BibliotecaApp.Services;
using Microsoft.AspNetCore.Mvc;
using Microsoft.EntityFrameworkCore;

namespace BibliotecaApp.Controllers
{
    public class AutorController : Controller
    {
        private readonly IAutorService _autorService;
        private readonly ApplicationDbContext _context; // ← Temporal

        public AutorController(IAutorService autorService, ApplicationDbContext context)
        {
            _autorService = autorService;
            _context = context;
        }

        // GET: AUTORS (REFACTORIZADO)
        public async Task<IActionResult> Index(string? buscar)
        {
            var autores = await _autorService.ObtenerTodosAsync(buscar);
            ViewBag.Buscar = buscar;
            return View(autores);
        }

        // GET: AUTORS/Details/5 (SIN CAMBIAR)
        public async Task<IActionResult> Details(int? id)
        {
            if (id == null) return NotFound();

            var autor = await _context.Autores
                .Include(a => a.Libros)
                .FirstOrDefaultAsync(m => m.Id == id);

            if (autor == null) return NotFound();

            return View(autor);
        }

        // GET: AUTORS/Create (SIN CAMBIAR)
        public IActionResult Create()
        {
            return View();
        }

        // POST: AUTORS/Create (SIN CAMBIAR)
        [HttpPost]
        [ValidateAntiForgeryToken]
        public async Task<IActionResult> Create([Bind("Id,Nombre,Nacionalidad,FechaNacimiento")] Autor autor)
        {
            if (ModelState.IsValid)
            {
                _context.Add(autor);
                await _context.SaveChangesAsync();
                return RedirectToAction(nameof(Index));
            }
            return View(autor);
        }

        // GET: AUTORS/Edit/5 (SIN CAMBIAR)
        public async Task<IActionResult> Edit(int? id)
        {
            if (id == null) return NotFound();

            var autor = await _context.Autores.FindAsync(id);
            if (autor == null) return NotFound();

            return View(autor);
        }

        // POST: AUTORS/Edit/5 (SIN CAMBIAR)
        [HttpPost]
        [ValidateAntiForgeryToken]
        public async Task<IActionResult> Edit(int? id, [Bind("Id,Nombre,Nacionalidad,FechaNacimiento")] Autor autor)
        {
            if (id != autor.Id) return NotFound();

            if (ModelState.IsValid)
            {
                try
                {
                    _context.Update(autor);
                    await _context.SaveChangesAsync();
                }
                catch (DbUpdateConcurrencyException)
                {
                    if (!AutorExists(autor.Id)) return NotFound();
                    else throw;
                }
                return RedirectToAction(nameof(Index));
            }
            return View(autor);
        }

        // GET: AUTORS/Delete/5 (SIN CAMBIAR)
        public async Task<IActionResult> Delete(int? id)
        {
            if (id == null) return NotFound();

            var autor = await _context.Autores.FirstOrDefaultAsync(m => m.Id == id);
            if (autor == null) return NotFound();

            return View(autor);
        }

        // POST: AUTORS/Delete/5 (SIN CAMBIAR)
        [HttpPost, ActionName("Delete")]
        [ValidateAntiForgeryToken]
        public async Task<IActionResult> DeleteConfirmed(int? id)
        {
            var autor = await _context.Autores.FindAsync(id);
            if (autor != null)
            {
                _context.Autores.Remove(autor);
            }
            await _context.SaveChangesAsync();
            return RedirectToAction(nameof(Index));
        }

        private bool AutorExists(int? id)
        {
            return _context.Autores.Any(e => e.Id == id);
        }
    }
}
⚠️ IMPORTANTE: Como los otros métodos (Details, Create, Edit, Delete) todavía usan _context, dejamos temporalmente el _context también inyectado para que los otros métodos sigan funcionando. Los refactorizaremos después.

6 Registrar el Servicio en Program.cs

Program.cs

Abrir Program.cs y agregar UNA línea antes de var app = builder.Build();:

using BibliotecaApp.Data;
using BibliotecaApp.Services;  // ← AGREGAR
using Microsoft.EntityFrameworkCore;

var builder = WebApplication.CreateBuilder(args);

builder.Services.AddControllersWithViews();

builder.Services.AddDbContext<ApplicationDbContext>(options =>
    options.UseSqlServer(builder.Configuration.GetConnectionString("DefaultConnection")));

// ✅ AGREGAR ESTA LÍNEA:
builder.Services.AddScoped<IAutorService, AutorService>();

var app = builder.Build();

// ... el resto queda igual ...
💡 ¿Qué hace esta línea? Le dice a ASP.NET: "Cuando alguien pida un IAutorService, dale una instancia de AutorService". Así funciona la inyección de dependencias.

🎯 ¿Qué aprendieron tus aprendices?

  • El controlador ya no consulta la base de datos directamente → ahora llama al servicio
  • La vista ya no recibe el modelo de dominio → recibe un ViewModel específico
  • El ViewModel puede tener datos calculados (como TotalLibros) que no existen en la base de datos
  • La interfaz permite inyectar dependencias → el controlador depende de IAutorService, no de AutorService
  • La arquitectura es consistente → todas las vistas usan ViewModel, nunca el modelo de dominio directamente
